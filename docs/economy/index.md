# 💰 النظام الاقتصادي والموارد (Economy System)

[← العودة إلى الفهرس الرئيسي](../README.md)

يوثق هذا الملف النظام الاقتصادي للعبة والمبني داخل [`src/game/economy/`](../../src/game/economy/).

---

## 📊 القيم الافتراضية الأولية

| المورد | القيمة الابتدائية | الوصف |
| :--- | :--- | :--- |
| **الذهب (Gold / Coins)** | `1000` | العملة الرئيسية لتمويل أعمال البناء وشق الطرق والصيانة |
| **الخشب (Timber / Wood)** | `50` | مادة البناء الأساسية للمباني الأولية |
| **معدل الاسترداد عند الهدم** | `50%` | استعادة نصف تكلفة الإنشاء عند هدم أي مبنى أو طريق |

---

## ⚙️ مدير الاقتصاد (`EconomyManager`)

- التحقق من كفاية الرصيد قبل الشراء (`hasSufficientFunds`).
- خصم التكلفة عند تأكيد البناء (`deductFunds`).
- إضافة الاسترداد المالي عند الهدم (`refund`).
- إرسال أحداث التحديث لواجهة المستخدم (`EconomyBar.tsx`).
