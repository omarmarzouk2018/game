# 🏝️ جزيرة إمباير ريلمز (The Island)

[← العودة إلى الفهرس الرئيسي](../README.md)

هذا الملف هو المرجع الأساسي الشامل لجميع مواصفات وأبعاد الجزيرة الطبيعية التي تدور عليها أحداث اللعبة.

---

## 📊 بطاقة المواصفات العامة والأبعاد (Quick Specs)

| الخاصية | القيمة الرياضية في الكود | الوصف والتفاصيل |
| :--- | :--- | :--- |
| **عرض الجزيرة (Width)** | `440.0` وحدة / متر | الامتداد على المحور الأفقي (X) |
| **عمق الجزيرة (Depth)** | `440.0` وحدة / متر | الامتداد على محور العمق (Z) |
| **مقياس الارتفاع (Height Scale)** | `3.6` | معامل ضرب الارتفاع الداخلي لتحقيق تضاريس واقعية |
| **دقة شبكة الأرض (Mesh Grid)** | `256 × 256` مقطع (Segments) | إجمالي `257 × 257` نقطة (Vertices) لتفاصيل التضاريس |
| **منسوب سطح البحر (Sea Level)** | `Y = 0.0` | كل ما هو أعلى يابسة، وما دونه قاع بحر |
| **أقصى عمق للمحيط (Max Depth)** | `-5.8` متر تقريباً | جرف صخري عميق ينحدر بسرعة للمحيط |
| **أعلى قمة جبلية (Max Mountain Height)** | `~55.0` متر تقريباً | السلسلة الجبلية الشمالية/الخلفية |
| **نظام الإحداثيات (Coordinates)** | مركز الجزيرة `(0, 0, 0)` | المجال الموحد ينتهي عند `[-0.5, 0.5]` على محوري X و Z |

## 🗺️ التكوين الجغرافي والمعالم الرئيسية (Geography & Landmarks)

```
                       [ الشمال / الخلف: Z موجب ]
                     ▲▲▲ سلسلة الجبال الخلفية ▲▲▲
                    ▲▲▲ (Alpine Mountain Spine) ▲▲▲
                          ▲▲ تلال سفلية ▲▲
                           (Foothills)
                                |
[ الغرب: X سالب ]             سهول مركزية              [ الشرق: X موجب ]
 خليج طبيعي واسع              منبسطة للبناء             غابات وتلال شرقية
 (Western Harbor / Bay)     (Central Plains)
                                |
                          شواطئ رملية هادئة
                     (Southern Sandy Beaches)
                       [ الجنوب / الأمام: Z سالب ]
```

1. **السهول المركزية (Central Plains):**
   - المنطقة المخصصة لقلب المدينة والمباني السكنية الأولية ومسارات الطرق. تضاريسها شبه منبسطة مع تموجات طفيفة لتسهيل البناء.
2. **الخليج الطبيعي الغربي (Western Harbor / Bay):**
   - قطع طبيعي في الساحل الغربي يتيح بناء الموانئ والأرصفة البحرية وتوليد السفن مستقبلاً.
3. **السلسلة الجبلية الخلفية (Mountain Spine):**
   - تقع في الثلث الخلفي (الشمالي) بين `Z: 0.15` و `Z: 0.75`، تتميز بقمم صخرية حادة تم توليدها باستخدام Ridged Multi-Octave Noise.
4. **السواحل والشواطئ (Coastlines & Beaches):**
   - تنقسم إلى نوعين:
     - **جروف صخرية حادة (Rocky Cliffs):** تشكل معظم المحيط الخارجي وتنحدر مباشرة لعمق المحيط.
     - **شواطئ رملية هادئة (Sandy Beaches):** تتركز في الساحل الجنوبي والغربي برصيف ساحلي تدريجي (Shallow Shelf).

## 📂 الفهرس التفصيلي لملفات الجزيرة (Island Sub-Topics)

عند الرغبة في معرفة التفاصيل الرياضية أو البرمجية الدقيقة لكل مكوّن، يُرجى مراجعة الملفات الفرعية المخصصة:

* ⛰️ **[تضاريس الجزيرة والارتفاعات (Terrain & Elevation Math)](terrain.md):**
  - معادلات الارتفاع، خوارزميات الضوضاء (Value Noise, FBM, Ridged Noise)، حسابات الميول (Slopes)، وتدرجات الجبال والسهول.
* 🌊 **[المحيط وقاع البحر (Ocean & Bathymetry)](ocean.md):**
  - خامة المياه، شيدر الأعماق (Depth Texture)، تموجات الأمواج، ورغوة الشواطئ التفاعلية.
* 🌲 **[الغطاء النباتي والبيئة (Biomes & Vegetation)](biomes.md):**
  - توزيع الغابات وتجمعات الأشجار (Tree Clusters)، خامات العشب، والصخور وتوزيعها الجغرافي.
