# 🛣️ شبكة الطرق والمسارات الطبيعية (Natural Road System)

[← العودة إلى الفهرس الرئيسي](../README.md)

يوثق هذا الملف نظام شبكة الطرق في اللعبة والمبني في المجلد [`src/game/roads/`](../../src/game/roads/).
يركز النظام على تجسيد **طرق ريفية طبيعية وواقعية (Organic Dirt Roads)** ككيان ثلاثي الأبعاد متداخل بسلاسة مع تضاريس الجزيرة، بدلاً من الشرائط المسطحة المرسومة كملصقات (Flat 2D Decals).

## 🎨 فلسفة التصميم البصري: مظهر طبيعي واقعي (Natural Visual Realism)

> [!IMPORTANT]
> **مبدأ التصميم الأساسي للطرق:**
> منع ظهور الطرق كرسوم مسطحة أحادية اللون أو مربعات هندسية حادة مقطوعة الزوايا. يجب أن تمتلك شبكة الطرق أشكالاً متعددة وطبيعية بناءً على طريقة اتصال كل مقطع بالمقاطع المجاورة، مع دمج التقاطعات وحواف المنعطفات عبر أقواس وانحناءات ناعمة (Curved Fillets & Flares).

### 1. الأشكال المتعددة لتقاطع واتصال الطرق (Multi-Shape Topological Junctions)
يتم تصنيف كل خلية طريق ديناميكياً وفقاً لاتصالها بالاتجاهات الأربعة (شمال، شرق، جنوب، غرب) عبر قناع طوبولوجي من 16 حالة (`RoadTileTopology`):
1. **المسار المستقيم (Straight Roads - N-S أو E-W):** مسار متصل باتجاهين متعاكسين مع أخاديد عجلات متوازية وأكتاف ترابية متدرجة.
2. **المنعطف المقوس (Curved Corners / Bends - NE, ES, SW, WN):** مسار يربط بين اتجاهين متعامدين بزاوية $90^\circ$، حيث تلتف أخاديد العجلات على شكل قوس دائري ناعم مع دمج الزاوية الداخلية والخارجية بنعومة بدلاً من القطع المربع الحاد.
3. **التقاطع الثلاثي المتفرع (3-Way T-Junctions):** مسار رئيسي يعبر باتجاهين ويتفرع منه مسار ثالث؛ يتميز بتوسيع نقطة الالتقاء (Flared Shoulders) وإضافة أقواس دائرية (Corner Fillets) على جانبي التفرع، مما يلغي الفجوات والتمزقات التي كانت تظهر بين الطرق المتعامدة.
4. **مفترق الطرق الرباعي (4-Way Crossroads):** ساحة دائرية ترابية مدمجة وواسعة تلتقي فيها أربعة مسارات مع آثار دوران دائرية وأقواس ناعمة في الأركان الأربعة.
5. **نهاية المسار المستديرة (Dead-End Caps):** نهاية مستديرة للمسار تتلاشى تدريجياً داخل عشب الجزيرة دون قطع حاد.
6. **البلاطة المنفردة (Isolated Turnaround):** مساحة ترابية مستديرة متدرجة الحواف.

### 2. التجسيم ثلاثي الأبعاد والتحديب (Crowned 3D Cross-Section)
- مسار الطريق ليس مستوياً؛ بل يمتلك مقطعاً عرضياً مقوساً (Crowned Profile):
  - **أخاديد العجلات (Wheel Ruts):** انخفاض غائر بعمق `-0.032m` على جانبي المسار حيث تدوس العجلات وتلتف مع المنعطفات.
  - **السنم الأوسط (Center Ridge):** ارتفاع مركزي طفيف بمقدار `+0.016m` يماثل تراكم الأتربة بين مسارات السير.
  - **الاستجابة لضوء الشمس:** هذه الفروق في الارتفاع تجعل ضوء الشمس المائل يلقي ظلالاً دقيقة وطبيعية داخل مسارب العجلات، مما يعطي إحساساً مادياً ثلاثي الأبعاد.

### 3. أطلس الخامات الإجرائي PBR رباعي الأرباع (4-Quadrant Texture Atlas)
يتضمن أطلس الخامات بحجم $512 \times 512$ أربعة أقسام مخصصة لكل شكل:
- **الربع العلوي الأيسر:** المسارات المستقيمة وأخاديد السير المتوازية.
- **الربع العلوي الأيمن:** المنعطفات المقوسة وأخاديد الالتفاف الدائري.
- **الربع السفلي الأيسر:** التقاطعات الثلاثية T-Junction وأخاديد التفرع المدمجة.
- **الربع السفلي الأيمن:** الساحات والتقاطعات الرباعية 4-Way Crossroads.

### 4. التدرج اللوني الطبيعي للتربة (Multi-tone Color Grading)
اللون ليس صبغة واحدة، بل تدرج معقد محسوب لكل رأس هندسي (Vertex Colors & PBR):
- **قيعان الأخاديد الرطبة:** تربة داكنة متماسكة ورطبة (`#402c1c` / `rgb(64, 44, 28)`).
- **أكتاف المسار وجوانبه:** تراب طميي دافئ مجفف بالشمس (`#7a5c3e` / `rgb(122, 92, 62)`).
- **حواف الغبار المتلاشية:** جزيئات غبار وتراب خفيف يتناثر نحو العشب (`#9e825e` / `rgb(158, 130, 94)`).

### 5. الحواف العضوية المتموجة (Organic Edge Alpha Blending)
- كسر الخطوط الهندسية المستقيمة عبر دالة تشويش موجية (`hash2D`).
- تتداخل حواف الطريق تدريجياً مع أعشاب الجزيرة بنمط متعرج غير منتظم، بحيث لا تظهر حافة حادة تفصل بين الطريق والعشب.

## 📌 المواصفات الحسابية والفيزيائية

| الخاصية | القيمة | الوصف |
| :--- | :--- | :--- |
| **عرض الطريق (Road Width)** | `2.0` متر / وحدة | عرض المسار الترابي الفعلي في المشهد |
| **عمق مسار العجلات (Rut Depth)** | `-0.032` متر | تجويف مسار العجلات بالنسبة للسطح |
| **ارتفاع التحديب الأوسط (Crown Height)** | `+0.016` متر | البروز الطفيف لوسط الطريق |
| **التكلفة لكل خلية (Cost per cell)** | `5` ذهب | تكلفة تشييد وحدة الطريق |
| **الاسترداد عند الهدم (Demolish Refund)** | `50%` | استرجاع الذهب عند إزالة الطريق |
| **أقصى انحدار مسموح (Max Slope)** | `35°` | منع مد الطرق فوق الجروف شديدة الانحدار |
| **لون المعاينة الصالحة (Valid Blueprint)** | `#00d2ff` (شفافية `0.60`) | لون المخطط الهندسي عند استيفاء شروط البناء |
| **لون المعاينة المرفوضة (Invalid Blueprint)**| `#ff4757` (شفافية `0.60`) | لون التحذير عند وجود عائق أو انحدار أو عجز مالي |

## 🕹️ تجربة المستخدم والمعاينة الشفافة عند المؤشر (Cursor & Blueprint UX)

- **المعاينة الشفافة ثلاثية الأبعاد على الأرض (3D Ground Blueprint Ghost):**
  - تتبع المؤشر بدقة متطابقة مع شبكة الجزيرة وارتفاع التضاريس فور اختيار الأداة.
  - إبراز الحدود الخارجية عبر خطوط شبكية مضيئة (`Wireframe Outline`) مع رفع أولوية المعالجة (`renderOrder = 999`) لمنع اختفاء المخطط تحت العشب ثلاثي الأبعاد.
- **الشارة الشفافة العائمة عند رأس المؤشر (2D Floating Cursor Ghost Badge):**
  - بطاقة زجاجية شبه شفافة تتبع مؤشر الفأرة فور تفعيل أداة الطريق أو المبنى.
  - تعرض اسم العنصر وتكلفته بالذهب وحالة الصلاحية (سماوي شفاف عند الصلاحية وأحمر عند التعذر).
- **حرية التحكم بالكاميرا أثناء البناء:**
  - إمكانية تحريك الكاميرا بحرية كاملة بالأسهم أو `WASD`، تدوير الزاوية بـ `Q/E` أو السحب بالزر الأيمن/الأوسط، والتقريب بعجلة الفأرة دون أن يتعطل وضع البناء.
